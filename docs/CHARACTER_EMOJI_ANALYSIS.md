# 캐릭터 · 이모지 · 그림, 꼭 필요할까요? (분석 노트)

> 12살 친구도 읽을 수 있게 쓴 문서예요.
> 질문: "육임을 쉽게 설명하려면 캐릭터나 그림이 필요할까?" → **이모지는 꼭 필요하고, 캐릭터와 그림 파일은 지금은 미뤄요.**

---

## 1. 왜 그림이 도움이 될까요?

- 육임에는 **칸 12개**, **카드 12장**, **힘 5단계**가 나와요. 글만 있으면 헷갈려요.
- 사람은 글자보다 **그림을 먼저, 더 빨리** 알아봐요. 🐭 하나만 봐도 "쥐 칸"이구나 알 수 있어요.
- 어려운 말을 없애도, 비슷한 글이 계속 나오면 눈이 피곤해요. 그림은 **쉬는 곳** 역할도 해요.

## 2. 세 가지를 비교해 봤어요

| 방법 | 좋은 점 | 어려운 점 | 결정 |
|---|---|---|---|
| **이모지** (🐭 🐉 🌙) | 파일이 필요 없어요. 앱이 가벼워요. 글자라서 기기마다 자동으로 맞춰 보여요. 스크린 리더가 읽어 줘요. | 기기마다 모양이 조금 달라요. 아주 새 이모지는 옛 폰에서 □로 보여요. | ✅ **지금 사용** |
| **글자 막대** (●●●○○) | 그림 파일이 없어요. "얼마나 센지"가 한눈에 보여요. | 모양이 단순해요. | ✅ **지금 사용** |
| **캐릭터 그림** (마스코트) | 앱에 개성이 생겨요. | 그림을 만들어야 해요. 파일이 커져서 느려져요. 열두 띠·열두 카드는 그림이 24장이나 필요해요. 그림 스타일이 하나라도 다르면 어색해요. | ⏸ **나중에** |
| **큰 그림·일러스트** | 보기에 화려해요. | 용량이 크고, 이미지 만들기에 시간·비용(크레딧)이 많이 들어요. | ⏸ **나중에** |

## 3. 이모지를 고를 때 지킨 약속

1. **오래된 이모지만 써요.** 새로 나온 이모지(예: 불새 🐦‍🔥)는 옛날 폰에서 안 보여서 뺐어요.
2. **뜻이 겹치지 않게** 골랐어요. 용 띠는 🐲(얼굴), 청룡 카드는 🐉(몸)처럼 나눴어요.
3. **장식으로만** 써요. 이모지가 안 보여도 글(이름)만으로 다 이해돼요. 막대(●○)에는 화면 읽기 도구가 읽지 않게 `aria-hidden`을 붙였어요.
4. 의미를 **틀리게 만들지 않아요.** 좋은 카드라고 해서 무조건 😊, 나쁜 카드라고 해서 😡로 정하지 않아요.

## 4. 그림이 늘어난 곳

- **시작·중간·마무리 카드**: 띠 이모지 + 기운 카드 이모지 + 힘 막대
- **네 칸 표**: 칸마다 띠 이모지
- **결과 화면 위쪽**: 이미 있던 분위기 이모지(☀️ 🙂 ⚖️ 🔀 ⚠️)
- **전체 흐름 아래**: 🎯 읽기의 또렷함

## 5. 캐릭터는 언제 만들면 좋을까요?

아래 조건이 **모두** 맞을 때 다시 생각해 봐요.

1. 사용자가 늘어서 "앱의 얼굴"이 필요해졌을 때
2. 그림 한 장을 **SVG 같은 가벼운 파일(수 KB)** 로 만들 수 있을 때
3. 12장짜리 그림을 같은 스타일로 한 번에 맞춰 만들 예산이 있을 때

그때까지는 **이모지 + CSS(색, 막대)** 로도 충분해요. 돈과 크레딧을 아끼고, 앱도 빨라요.

## 6. 한 줄 정리

> **글은 쉽게, 그림은 이모지로 가볍게.** 캐릭터와 큰 그림은 앱이 더 커진 다음에 해도 늦지 않아요.
