## 8. 글을 "쉬운 말"로 바꾼 작업 (2026-08-14)

앱이 보여 주는 답이 어른용 문어체라 어려웠어요. 그래서 **초등학교 고학년(12살)이 읽어도
이해되는 말**로 전부 다듬었습니다. **계산 방식은 하나도 건드리지 않았어요.**

무엇을 바꿨는지:

- **해석 사전** (`domain/liuren/data/courses.json`) — "○○과는 … 과입니다" 식으로 옛 이름을
  그대로 읽어 주던 문장을 전부 "… 때입니다"로 바꿨어요. 안목·관례·내실·타이밍·디테일 같은
  어려운 낱말도 쉬운 우리말로 교체했습니다.
- **기운 카드 사전** (`generals.json`) — 화면에 나가는 단계별 문장에서 초반→처음, 마찰→부딪힘,
  분쟁→다툼, 조력자→도와주는 사람처럼 쉬운 말로 바꿨어요.
- **화면 표기** (`labels.ts`, `TransmissionCards.tsx`, `CourseDiagram.tsx`, `ReadingView.tsx`)
  - 초전·중전·말전 → 🌱 시작 · 🔄 중간 · 🏁 마무리
  - 천반/지반 → 위 칸/아래 칸, 과전도(四課) → 상황을 네 칸으로 본 표
  - 천장 → 기운 카드, 기세(왕·상·휴·수·사) → 힘(아주 셈 … 많이 약함), 공망 → 아직 빈 자리
  - 지지 한자(子·丑…) → 열두 띠 동물(쥐(자)·소(축)…) — 한자는 화면에서 완전히 없앴어요.
  - 심화 해석 → 더 자세한 해설, 예상되는 변수 → 달라질 수 있는 점
- **어려운 말 풀이** (`glossary.ts`) — 옛 용어 사전을 버리고, 화면에 실제로 쓰는 쉬운 말
  11개를 설명하는 사전으로 다시 썼어요.

### 콘텐츠 테스트 추가

`tests/content.test.ts`를 새로 만들어 아래 네 가지를 자동으로 검사합니다. (8개 테스트)

1. 화면에 나가는 글에 **한자가 없을 것**
2. 어려운 용어(과체·삼전·공망·천장 …)가 **그대로 나오지 않을 것**
3. 한 문장이 **70자를 넘지 않을 것**
4. 화면에 쓰는 쉬운 말은 모두 **"어려운 말 풀이"에 설명이 있을 것**

검사 범위는 사전 데이터뿐 아니라, 여러 시각으로 **실제 생성한 기본 해설·자세한 해설**까지

## 10. 질문에 바로 답하도록 고친 작업 (2026-08-30)

- 예전에는 질문을 저장만 하고, 실제 답을 만들 때는 쓰지 않았어요. 그래서 “내일 만남이

- 이제 질문에서 즐거움·시기·선택·관계 같은 뜻을 찾아, 육임 결과에 맞는 답을 첫 문장에

- 기본 해설을 **답 → 이유 → 지금 할 일** 세 부분으로 줄였습니다. 자세한 해설도 기본 답을
  되풀이하지 않아 전체 글이 이전의 절반 정도가 되었습니다.
- AI 서버나 돈이 드는 서비스는 넣지 않았습니다. 인터넷이 없어도 같은 질문과 시각에는
  같은 답이 나오며, 비밀키도 필요 없습니다.
- 질문 낱말을 `questionKeywords.ts`에 종류별로 모았습니다. 연애·일·분실·여행·건강에서
  쓰는 생활 표현과 묶음말을 함께 찾고, 단서가 여러 개면 점수를 비교해 주제를 정합니다.
- `분실·이동` 안에서도 “열쇠를 잃어버림”은 분실, “제주로 여행”은 이동으로 나눕니다.
  `가방`, `갈까`처럼 뜻이 여러 개인 짧은 말은 혼자서 주제를 정하지 못하게 했습니다.

## 12. 앱인토스 SDK를 3.4.0으로 올린 작업 (2026-09-14)

### 왜 했나요?

- 토스에서 앱인토스 SDK는 **3.1 버전 이상**을 쓰라고 안내하고 있어요.
- 이 프로젝트는 `2.10.7`(2 버전대)을 쓰고 있어서, 안내에 맞게 최신 버전으로 올렸어요.

### 무엇을 바꿨나요?

- `package.json`의 `@apps-in-toss/web-framework`를 `2.10.7` → `3.4.0`(현재 가장 최신 정식 버전)으로 올렸어요.
- SDK 3버전은 설정 파일 이름과 형식이 달라져서, 토스가 제공하는 자동 변환 명령
  (`npx ait migrate v3`)을 실행해 안전하게 옮겼어요.
  - `granite.config.ts` → `apps-in-toss.config.ts`로 이름과 내용이 바뀜(아이콘 설정은 이제
    토스 파트너 콘솔에서 직접 등록해요).
  - `package.json`의 `build` 스크립트 끝에 `ait build`가 자동으로 붙어서, 이제
    `npm run build` 한 번이면 배포용 `.ait` 파일까지 같이 만들어져요(타입 검사(`tsc`)는
    그대로 유지되도록 다시 넣어 뒀어요).
  - 개발용 도구 `@apps-in-toss/devtools`가 새로 추가돼서, 컴퓨터 브라우저에서도 토스 앱
    흉내를 내며 개발할 수 있어요.
- 광고(`GoogleAdMob`)와 앱 닫기(`closeView`) 코드는 SDK 3버전에서도 그대로 쓸 수 있어서
  고치지 않았어요.

### 꼭 기억해야 할 점

- ⚠️ SDK 3버전 이상으로 한 번 출시하면 2버전으로 다시 되돌릴 수 없어요. 그래서 출시 전에
  QR코드로 충분히 테스트해야 해요.
- ⚠️ SDK 3버전부터는 CORS(어떤 주소에서 온 요청을 허용할지 정하는 규칙)가 바뀌어요.
  아래 두 주소를 토스 파트너 콘솔의 "허용 주소" 목록에 등록해야, 광고 같은 기능이
  막히지 않아요.
  - `https://today-liuren.web.tossmini.com` (실제 서비스용)
  - `https://today-liuren.private-web.tossmini.com` (콘솔 QR 테스트용)
